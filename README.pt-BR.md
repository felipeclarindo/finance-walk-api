# Finance Walk API

API Rest para fazer o controle dos custos na caminhada de project finance integrado ao banco de dados oracle.

## Passos para instalação e execução

1. Clone o repositório:

```bash
git clone https://github.com/felipeclarindo/finance-walk-api.git
```

2. Entre no diretório:

```bash
cd finance-walk-api
```

3. Execute o projeto:

```bash
dotnet build
```

4. Entre no repositorio do build:

```bash
cd C:\team-track\app\bin\Debug\net9.0
```

5. Execute o arquivo:

```bash
dotnet app.dll
```
